Two typefaces — one for display (Instrument Serif) and one for everything else (Hanken Grotesk). Both are free from Google Fonts; install locally before exporting logos for print.

Usage Rules

Applied consistently, these keep the brand cohesive across every surface — website, ads, letterhead, email, third-party templates.

Do

  • Use the primary logo wherever space permits (~180px wide or more on screen; 1.25" wide or more in print).
  • Use the mark alone at small sizes, favicons, social avatars, business-card backs.
  • Maintain clear space — at minimum, the height of the compass mark on all sides.
  • Keep the gold italic "&" — it's the single distinguishing accent. Never make it upright, never change its color.
  • Use white variant on dark backgrounds; dark variant on white and light backgrounds.

Don't

  • Don't stretch, skew, rotate, or recolor the logo outside the approved dark/white variants.
  • Don't add effects — drop shadows, glows, gradients, outlines. The logo is flat and stays flat.
  • Don't use the gold as a text color anywhere except the italic "&" in the wordmark and the center dot of the mark.
  • Don't place the dark logo on dark backgrounds, or the white logo on light backgrounds. Contrast matters more than any stylistic preference.
  • Don't use Instrument Serif for body copy — it's a display face and loses legibility below 16pt in print.

Using These Files

SVG files are vector. They scale to any size without loss of quality. Most modern design tools (Canva, Figma, Illustrator, InDesign) accept SVG directly. For platforms that require PNG or PDF (some newspaper ad managers, older printers), convert using the steps below.

Converting SVG to PNG or PDF

  • Quick on Mac: Double-click the SVG to open in Preview → File → Export As → PDF or PNG. For PNG, set resolution to 600dpi for print quality.
  • Free online: cloudconvert.com → Upload SVG → Select PNG or PDF → Set resolution to 600dpi → Download.
  • In Canva: Upload SVG → drag onto canvas → Export as PNG or PDF with "print quality" selected.
  • For newspaper ads: Most CT papers accept PDF or 300dpi PNG. Request a PDF with embedded fonts if the paper supports it.

If You Give This to a Designer or Agency

  • Share the entire brand-assets folder — they'll get all variants plus color and font specs.
  • Fonts are free: fonts.google.com/specimen/Instrument+Serif and fonts.google.com/specimen/Hanken+Grotesk.
  • Have them work from SVG files as the source of truth. Rasterized PNGs should only be final output, never the working file.
