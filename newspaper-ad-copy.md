## PLACEMENT STRATEGY

| Publication | Section | Why |
|---|---|---|
| Hartford Courant | Classifieds: Real Estate Wanted | Largest CT daily, most seller eyeballs |
| New Haven Register | Obituaries adjacency | Estate executors read this section daily |
| Republican-American (Waterbury) | Legal Notices adjacency | Foreclosure notices run here; distressed sellers scan |
| Connecticut Post (Bridgeport) | Sunday real estate section | Higher weekend readership |
| Local weeklies (Rep-Am, Patch, etc.) | Community classifieds | Cheaper; tighter geographic targeting |

**Run frequency:** Weekly, same publication, same slot, for 8+ weeks before evaluating. Real-estate direct-sale ads build by repetition — a single insertion usually generates little. Budget ~$150–$400/week per paper for a 2x3 display.

**Tracking:** Use the `(475) 374-1073` number across all placements for now, but tag responses by which paper they call from so you can compare CPL (cost per lead) across publications after 4–6 weeks.

## WHAT'S INTENTIONALLY NOT IN THESE ADS

- No "Est. 1998" or any founding year
- No "1,400+ homes" or any volume claim
- No "BBB Accredited" badge or similar
- No "family-owned" unless that's actually true of the LLC
- No customer quotes or testimonials
- No dollar ranges, guaranteed prices, or "top dollar" claims
- No "we'll beat any offer" or competitive pricing language

Everything above the Equal Housing line is a verifiable description of the service, not a performance claim.

---

## REQUIRED DISCLAIMERS TO ADD IF YOU EXPAND

If you later add any of the following, the ad needs different language:

- **Quoting a specific price or price range** → requires "sample property" or "example" language + ranges backed by actual transactions
- **Guaranteeing a close timeline** → only if you're financially positioned to deliver it every time
- **Using "approved" or "certified" anywhere** → only with the specific issuing body named
- **Mentioning "licensed"** → only if the LLC actually holds a CT license and the license number is shown
- **Any "limited time" or "act now"** → generally fine but CT CUTPA looks at high-pressure language in distressed-seller contexts
